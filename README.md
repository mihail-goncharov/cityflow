# CityFlow Analytics

Portable Data Engineering and Analytics Platform.

## Technology Stack

- Python / Polars
- RustFS (S3-compatible object storage)
- DuckDB
- dbt
- Dagster
- Streamlit / Plotly
- Docker Compose
- Forgejo CI/CD

## Deployment

- Local development (Docker)
- Proxmox homelab
- Optional public cloud
